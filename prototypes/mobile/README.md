# 타임캡슐 모바일 UI/UX 시안

- 작성일: 2026-11-01. 사용자가 제공한 2026-10-27 기획안과 기존 길소리 초안을 통합했습니다.
- 적용 스킬: k-style-ui-ux 0.18.1 (`go` + `max`).
- `out/index.html`: 전체 화면 캔버스, 화면 확대, 흐름, 정책, 팔레트 3종, Foundation·Components.
- `out/screens/welcome.html`: 처음 사용 흐름을 따라가는 클릭형 시안.
- `out/screens/home.html`: 홈부터 시작하는 클릭형 시안.
- `out/prd.md`: 사용자가 제공한 원문과 통합 참조.
- `out/journey.md`: 사람별 여정, 고정된 가상 데이터, 해석과 가정.
- `out/spec_inventory.json`: 요구사항과 화면 대응.
- `out/research-notes.md`: 차량 API 검증 과제.
- `out/market/`와 `out/conventions.json`: 스토어 기반 시장 관례 조사.
- `out/credits.json`: 사진 출처와 검토용 이용 범위. 사진은 실제 가족 기록이 아닙니다. 공개 제출 전 사용권을 확보한 사진으로 교체합니다.

## 보는 방법

현재 로컬 서버는 `http://127.0.0.1:8790/`입니다. 외부로 공개하지 않았습니다.

다시 실행하려면 이 폴더에서:

```sh
python3 -m http.server 8790 --bind 127.0.0.1 --directory out
```

## 범위

시안의 계정·차량 연결·녹음·재생·위치 잠금·공유·구독은 화면 흐름 예시입니다. 실제 계정 생성, 녹음 업로드, 위치 수집, 차량 제어, 결제는 수행하지 않습니다. 차량 개념 화면을 모바일 프로덕션 UI로 오인하지 않도록 별도 그룹으로 표시했습니다.

음성은 장소·날짜·권한 조건이 모두 맞아야 들을 수 있다는 제품 규칙을 화면에 반영했습니다. 모바일 앨범 공유로 원격 재생을 우회하지 않습니다. 녹음 전 동승자의 동의 확인을 포함하되, 알림음만으로 동의가 성립한다고 주장하지 않습니다.

저장소가 아닌 독립 기획 폴더에서 제작한 시안이며 기존 코드 저장소나 브랜치는 수정하지 않았습니다. Pleos SDK 설치·접근 승인·실차 검증은 이 UI 작업과 별도입니다.
