# 타임캡슐 시안 검토 메모

작성일: 2026-11-01. 사용자 제공 원문은 2026-10-27 기획이다. 이 메모는 원문을 수정하거나 기능을 제거하지 않고, 사실·제안·검증할 사항을 구분한다.

## 통합 원칙

- 이름은 타임캡슐(가칭)로 바꾼다. 초기 길소리의 상호 팔로우와 현장에서만 음성 청취하는 조건은 유지한다.
- 모바일 화면은 탐색·캡슐 관리·가족/팔로우·여행 준비·차량 연결·개인정보 관리에 집중한다. 녹음·현장 재생은 차량 흐름을 별도 시안으로 포함한다.
- 가족 계정은 공유 비밀번호가 아니라 각자의 계정이 가족 공간에 참여하는 흐름을 가정한다. 탈퇴·차단·초대 취소와 가족 접근 범위를 구분해야 한다.
- 원격 모바일 상세·앨범·공유 링크에서 음성 재생, 자막 전체, 음성 다운로드로 장소 잠금을 우회하지 않는다. 목록은 제목·장소·날짜 등 메타데이터를 보여준다.
- 작성 직후 확인용 미리듣기와 봉인 이후 타인/본인의 청취 조건을 분리해 정의한다. 개봉 날짜가 지나도 장소 조건은 남는다.
- 수신자 지정은 원문에서 확장 단계지만 전체 시안에는 확장 기능으로 포함한다. ‘그날처럼’도 비전 설정/설명 화면으로 포함하며 동작 완료를 주장하지 않는다.

## 반드시 구분해야 할 기술 사실

| 원문의 가정 | 확인해야 하는 이유 | 시안 처리 |
|---|---|---|
| Wiper 작동 = 비 | 세척·수동 작동도 가능하다. | 자동 분위기는 추정이며 수정 가능한 태그로 표시한다. |
| Light 전조등 = 밤 | 주간·터널에서도 켜질 수 있다. | 밝기/시간 등 미확인 데이터로 밤을 확정하지 않는다. |
| Seat = 탑승 인원·누구와 함께 | 좌석 위치/각도 기능과 탑승 감지·신원은 다르다. | 동행자는 사용자 선택으로 표현하고 자동 인원은 검증 전 확정하지 않는다. |
| HVAC = 외기온도 | 도메인에 제공되는 실제 필드를 확인해야 한다. 온도만으로 계절을 확정할 수 없다. | 원시 상태와 감성 태그를 구분한다. |
| Toll = 통과 이벤트 | 현재 확인된 개요는 하이패스 음성 안내 음량 등의 조회/설정이다. | 자동 고속도로 통과 챕터는 검증 대상이다. |
| Door + 정차 = 도착 / 미러 접힘 = 시동 종료 | 상태 조합은 도착·여행 종료의 확실한 증거가 아니다. | 자동 감지 제안에 사용자의 확인·취소를 둔다. |
| Brake = 급제동 | 페달 상태만으로 급제동을 판별할 수 있다고 단정할 수 없다. | 안전 중단은 지원되는 신호와 플랫폼 정책 확인 후 구현한다. |
| NaviHelper 경로 = 현재 근접 위치 | 경로에 포함됐다는 사실은 실제 접근·방문을 증명하지 않는다. | 위치 확인 불가 상태에서는 잠금을 유지한다. 경로 기반 대안으로 현장 검증을 대체하지 않는다. |
| 핸들 버튼/Gleo 호출 | 서드파티 호출 연결·사용 권한·음성 녹음 수명주기는 미검증이다. | 차량 음성 흐름은 개념 시안으로 명시하고 정차 버튼 대안도 포함한다. |
| Vehicle State 사용 가능 = 모든 도메인 값 사용 가능 | 차종·기능·퍼미션·capability에 따라 다를 수 있다. | 태그 확인/지원하지 않는 상태를 제공한다. |

## 안전·프라이버시의 빈틈

- 알림음은 녹음 사실을 알리지만 동승자 전원의 동의를 자동으로 확보하지 않는다. 최초 녹음 안내와 동행자 확인을 둔다.
- 주행 중 음성이라고 자동으로 허용되는 것은 아니다. 실제 앱 분류·플랫폼 정책·오디오 포커스를 검증해야 한다. 모바일에는 주행 중 조작 제한 상태가 필요하다.
- ‘차가 바뀌어도 18년 보관’은 장기 비전이다. 데이터 내보내기·계정 복구·서비스 종료·동의 철회·백업 정책이 필요하다. 구독 미갱신만으로 기억이 즉시 소실되는 화면은 피한다.
- 캡슐 위치는 가족의 집·학교·생활동선을 드러낼 수 있다. 위치 공유 범위와 차단·삭제를 일관되게 설계한다.
- 차량 매각 시에는 계정 백업 확인 후 기기 삭제를 진행한다. 클라우드 원본 삭제와 기기 삭제는 다른 행동이다.
- 계정 이전은 성년 자녀에게 공유 권한을 주는 흐름과 전체 소유권 이전을 구분한다. 법적 상속을 앱 버튼 하나로 보장하지 않는다.

## 일정·심사 표현

- 작성 시점은 2026-11-01이므로 10월 28일 설명회는 미래 일정으로 표시하지 않는다.
- 17/20은 사용자 목표 점수이며 공식 배점이 아니다. 이미 수상 가능성이 검증됐다고 쓰지 않는다.
- ‘이전 대상작 두 편은 모두 아이용 AI 동화’는 이번 작업에서 출처 검증되지 않았다. 차별성 근거로 단정하지 않는다.
- ‘SDK 10개 사용’ 자체가 좋은 기술 활용성은 아니다. 핵심 경험에 실제로 필요한 데이터와 검증된 호출이 중요하다.
- 공개 가이드의 최종 입점/배포는 보장이 아니다. 사용자 원문 ‘적극 검토’도 확약 문구로 UI에 넣지 않는다.
- 사업 가격은 미정이다. 가상 가격을 사실처럼 표시하지 않고 시안 견본 가격을 쓰면 예시임을 정책에 명시한다.
