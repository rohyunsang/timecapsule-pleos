# 타임캡슐 차량 앱 프로토타입

같은 길에서 다시 만나는 목소리. Pleos Connect를 목표로 설계한 차량 앱의 웹 프로토타입입니다. 이 폴더는 웹 프로토타입입니다. 실제 Kotlin APK와 Pleos 에뮬레이터 연동은 별도 [네이티브 프로젝트](../timecapsule-android/README.md)에 구현했습니다. Pleos App Market 승인과 실차 검증은 아직 진행하지 않았습니다.

## 실행

이 폴더에서 `python3 -m http.server 8791 --bind 127.0.0.1`을 실행하고 `http://127.0.0.1:8791/`을 엽니다. 마이크 녹음에는 localhost 또는 HTTPS와 브라우저 권한이 필요합니다. HTML 파일을 직접 열기보다 서버를 사용하세요.

## 주행 청취 시연

1. 하단 `주행 청취 설정`을 누르고 주차 상태에서 `주행 청취 켜기`를 선택합니다. 기본값은 꺼짐입니다.
2. 하단에서 `개봉일 이후`, `수신 권한`, `위치 최신·정확`을 켭니다. `장소 안`은 아직 끕니다.
3. `주행 시뮬레이션`을 켠 뒤 `장소 안`을 켭니다. 실제 오디오가 재생됩니다. 브라우저가 자동 재생을 막으면 화면의 `듣기`를 누르세요.
4. `내비·통화 우선` 또는 `안전 경고`를 켜면 즉시 멈춥니다. 해제해도 자동으로 재개하지 않습니다.
5. `장소 안`, `수신 권한`, `위치 최신·정확`을 각각 끄면 재생이 중단됩니다. 재진입만으로 반복 재생하지 않습니다.
6. 주행 중 목록·공유·설정 화면으로 이동할 수 없습니다. `이번에는 듣지 않기`로 이번 이동의 재생을 미룹니다.

하단 체크박스는 검토용 입력입니다. 실제 차량, GPS, 날짜, 계정 서버의 신호가 아닙니다. 페이지를 새로고침하면 이동 세션은 초기화되며 청취 설정만 이 브라우저에 유지됩니다.

## 실제 녹음

주차 상태에서 홈 → 목소리 남기기 → 동승자 동의 확인 → 실제 녹음을 선택합니다. 최대 30초까지 녹음하고 미리 들을 수 있습니다. 녹음 중 주행·안내·안전 경고 입력이 들어오면 중단하고 폐기합니다. 녹음 원본은 브라우저 메모리에만 있으며 새로고침하면 사라집니다. 삭제 버튼은 Blob URL을 해제합니다. 현재 저장 완료 화면은 지속 저장 기능을 뜻하지 않습니다.

`audio/demo.wav`는 직접 작성한 문장을 macOS Yuna로 합성한 검토용 안내입니다. 실제 가족·아동의 목소리가 아닙니다. 실제 서비스를 출시할 때는 별도로 확보한 안내 음성 또는 허용된 TTS를 사용합니다.

## 파일과 검증

- `app.js`, `style.css`: 차량 UI 및 기획 화면
- `listening-policy.js`: 청취 조건과 장소 진입 정책
- `listening.js`: 실제 오디오·마이크 및 주행 상태 전이
- `test-listening.cjs`: 12개 정책 검사
- `test-listening.py`: Playwright에서 실제 오디오 시간 진행, 녹음 Blob 생성, 중단 등 검사
- `listening-validation.json`: 브라우저 검사 결과
- `submission/타임캡슐_공모전_접수양식.docx`: 공식 양식에 작성한 기획서. 참가자 정보·동의·서명은 비워두었습니다.

기록된 브라우저 검증은 Chromium의 가상 마이크 입력을 사용했습니다. 사람이 실제 마이크로 녹음한 품질 검증이나 Pleos 실차 검증과 다릅니다.

## 미구현 범위

이 웹 폴더에는 차량 SDK를 직접 연결하지 않았습니다. 별도 네이티브 프로젝트에서 Kotlin APK, Pleos SDK 기어·위치·방향지시등, 로컬 저장과 Android 오디오 포커스를 구현하고 에뮬레이터에서 검증했습니다. Gleo 음성 명령, 암호화 내보내기, 계정 인증, 가족·팔로우 서버, 클라우드 동기화, 외부 공유와 내비 실행은 후속 범위입니다. 위 기능의 기존 화면은 UI 시연입니다. 순수 오디오의 주행 사용 허용 범위도 운영 측의 승인 확인이 필요합니다.

1280×720과 600×720은 검토용 CSS 뷰포트이며 실제 Pleos 규격을 뜻하지 않습니다. 시스템 상태 표시줄·계기·공조를 앱이 대체하지 않습니다. 지도는 자체 제작한 설명용 도형입니다.

공식 설계 출처와 비교 내용은 `research/design-review.md`, 변경 전후는 `research.html`에 정리했습니다. 기존 리서치 화면은 2차 디자인 시점의 기록이며 이번 동작 변경은 이 README를 우선합니다.
