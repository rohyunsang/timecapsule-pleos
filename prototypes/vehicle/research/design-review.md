# 타임캡슐 차량 UI 리서치와 개선 · 2026-11-01

## 조사 범위

공식 가이드와 실제 제조사 화면을 대상으로 한 데스크 리서치입니다. 운전자 인터뷰, 실제 운전 실험, 차량 탑재 검증은 수행하지 않았습니다. 아래 관찰과 적용은 사용자 조사 결과가 아니라 디자인 판단입니다.

| 레퍼런스 | 확인한 내용 | 적용 | 그대로 적용하지 않은 것 |
|---|---|---|---|
| [Pleos UI Design Guide](https://document.pleos.ai/docs/connect/guide/docs-design/Introduction/intro) | 짧은 시간에 읽히는 핵심 정보, 단순 조작, 대비, 주야간 | 큰 제목, 짧은 안내, 주행 조작 제한, 밝기별 색상 역할 | 웹의 CSS 픽셀을 실차 mm/sp 충족으로 간주하지 않음 |
| [Pleos Display Layout](https://document.pleos.ai/docs/connect/guide/docs-design/getting-started/layout) | 시스템 UI와 앱 창의 분리, 창 크기 적응 | 내비 영역을 침범하지 않는 전체·분할 창 | 차량 계기·공조를 앱 메뉴로 흉내 내지 않음 |
| [Android Automotive Playing media](https://developers.google.com/cars/design/automotive-os/apps/media/interaction-model/playing-media) | 공식 재생 화면 이미지를 확인. 콘텐츠 정보와 하단 조작 분리, 재생·일시정지의 높은 중요도 | 장소 표지와 녹음 정보 분리, 큰 일시정지 버튼, 명확한 시간 표시 | 18초 편지에 셔플·반복·다음 곡 버튼을 추가하지 않음. Pleos 규칙으로 오인하지 않음 |
| [Polestar 4 공식 Infotainment](https://www.polestar.com/us/polestar-4-models/polestar-4-coupe/technology/) | 공식 디스플레이 이미지 확인. 지도 영역과 미디어/바로가기 영역 분리 | 홈에서 녹음과 여행을 두 영역으로 구분. 분할 창에서는 지도 중복 축소 | 제조사 시스템 UI 전체, 브랜드 자산, 색상 및 로고를 복제하지 않음 |
| [Android Design for Cars](https://developer.android.com/design/ui/cars) | 주행 경험과 주차 경험 구분 | 주행 상태에서 편집·탐색 차단 유지 | Android Auto 승인 조건을 Pleos 승인 조건으로 대체하지 않음 |

참고 이미지는 검토 중에만 확인했으며 앱이나 배포 ZIP에 복제하지 않았습니다. 바다 표지는 자체 SVG 도형입니다.

| P1 | 메뉴 | 하위 화면에서 상위 메뉴 선택 표시 소실 | 위치의 일관성 | 현재 위치를 알기 어려움 | 하위 화면에도 상위 메뉴 강조, aria-current | DOM 확인 |
| P2 | 공통 | 모든 카드에 테두리 반복 | 불필요한 장식 | 정보 중요도 희석 | 정보 카드 테두리 제거, 버튼 경계는 유지 | 주야간 캡처 확인 |

## 제품 판단

- 장소/날짜/권한은 색상만으로 알리지 않고 아이콘과 상태 문구를 함께 표시합니다.
- 지도는 경로 제공 기능이 아니므로 분할 창 홈에서는 숨기고, 동일한 여행 보기 동작은 유지합니다.
- 표지는 사진처럼 실제 기억의 증거로 보이지 않도록 추상 도형으로 구성했습니다.
- 녹음과 저장 확인 흐름, 삭제, 가족, 동기화 등 기존 41개 시나리오를 보존했습니다.
- 2045년 개봉 시나리오와 현재 사용 시나리오는 시연 데이터이며 실제 시간 판정 기능은 아닙니다.

## 다음 실차 검증 항목

실제 인셋·디스플레이 밀도에서 글자 높이, 터치 정확도, 햇빛·야간 반사, 운전석 도달 거리, 한국어 TTS 길이, 오디오 포커스 전환을 검증해야 합니다. 검토용 뷰포트에서 가로 넘침이 없다는 사실만으로 실차 안전을 입증하지 않습니다.
