# 네이티브 수집 지도 검증

2026-11-03에 중단된 `native-collected-map` 작업을 재개했습니다. 최신 원격 `integration`의 `ba44bd6`을 통합했으며, 홈 화면·음성 녹음·내비 위 재생 막대 변경을 보존했습니다. WebView 크기 수정과의 충돌은 WebView를 제거한 MapLibre 구현으로 해결하고 MapView에도 화면 크기를 명시했습니다.

## 자동 검증

- JDK 21에서 `bash gradlew :app:testDebugUnitTest :app:assembleDebug :app:lintDebug :app:assembleRelease`가 통과했습니다.
- 단위 테스트 58개, 실패·오류·건너뜀 0개입니다. 지도 대상 필터, 같은 좌표의 캡슐 묶음, 오래되거나 미래 시각인 차량 위치 제외를 포함합니다.
- Android Lint 오류 0개, 경고 81개입니다. 경고가 없는 상태는 아닙니다.
- `python3 scripts/verify-migrations.py`로 Room v1·v2·v3에서 v4로 전환할 때 캡슐·날짜 잠금·공유 필드와 schema 보존을 확인했습니다.
- `git diff --check`를 통과했습니다.

## 에뮬레이터 확인

`TimeCapsule_Pleos` 차량용 Android 에뮬레이터에 debug APK를 설치했습니다. 기존 DB를 백업한 뒤 검증용 캡슐 3개와 합성 음원을 사용했습니다. 이 검증은 실제 현장 수집이나 실차 주행의 증거가 아닙니다.

- 지도 배경 타일, 출처, 숫자 마커와 하단 목록이 표시됩니다.
- 같은 좌표의 캡슐 2개가 숫자 2로 묶이고 마커를 누르면 선택이 A에서 B로 바뀝니다.
- 현재 위치와 전체 보기 버튼을 실행했습니다. 위치 수신이 화면의 주기적 시각 갱신보다 먼저 도착하면 위치를 미래 값으로 오판하던 문제를 수정했습니다. 새 위치를 비교할 때 실제 현재 시각을 사용합니다.
- 길 안내 버튼을 누르면 기존 경로가 바뀐다는 확인창이 표시되며 취소할 수 있습니다. 실제 Pleos 경로 설정 완료는 검증하지 않았습니다.
- 마이크 권한을 거절하고 주행 준비를 하지 않은 상태에서 수집 캡슐의 재생 화면으로 진입했습니다. 원본 음질이나 실차 오디오 출력은 검증하지 않았습니다.
- 확인한 실행 중 AndroidRuntime의 치명적 예외가 없었습니다.

## 산출물과 남은 범위

APK·빌드 로그·Lint 보고서·화면 캡처는 로컬 `artifacts/timecapsule-native-map-20261103`에 보관했습니다. release APK는 서명되지 않았으므로 제출용 APK가 아닙니다.

지도 렌더러는 MapLibre Native이고 위치·길 안내 연결은 기존 Pleos NaviHelper를 사용합니다. Pleos 자체 Map SDK를 사용한 것으로 설명하지 않습니다. Firebase 운영 계정과 공유 철회, 실제 차량의 위치·주차 상태 변화, 내비 경로 설정 완료는 별도 검증이 필요합니다.
