# TC 모바일 앱 구현 및 검증 기록

## 구현 목표
기존 `ym/prototypes/mobile/out`의 79개 화면 시안을 참고하되 최신 정책을 우선한다. 모바일에서도 실제 장소를 방문해 수집할 수 있으며 수집 후에는 차량과 모바일 어디서든 재생한다. AI 요약과 자동 녹취는 구현하지 않는다. Android 에뮬레이터와 Firebase 에뮬레이터는 실행하지 않는다.

## 구성
- `app`: 기존 Pleos 차량 앱
- `shared`: 양쪽에서 사용하는 Firebase 계정, 친구, 캡슐 모델과 동기화 계약
- `mobile`: 별도 설치 가능한 Android Compose 모바일 앱 (구현 예정)

## 연동 및 개인정보
‘나만’ 캡슐은 사용자가 동기화를 켜기 전까지 차량 밖으로 업로드하지 않는다. 새 서버 컬렉션과 규칙은 소스에 추가하고 실제 배포 여부를 별도로 기록한다. 클라이언트 GPS 검사는 정상 앱의 수집 조건이며 악의적인 변조 기기의 위치 증명이라고 주장하지 않는다. 서버 설정이 없으면 설정 필요 화면을 제공하고 가짜 서버로 성공 처리하지 않는다.
