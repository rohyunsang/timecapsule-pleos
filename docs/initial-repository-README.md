# 타임캡슐 (Time Capsule)

> 그 길에 묻어둔 목소리가, 다시 그 길에서 당신을 기다린다.

현대자동차그룹 차량용 앱 개발 공모전(2026) 출품작입니다. 여행 중 차 안에서 목소리를 녹음해 그 장소에 묻어두면, 시간이 지나 같은 길을 다시 지날 때 차가 그 목소리를 꺼내 들려주는 **Pleos Connect** 앱입니다. 비, 밤, 함께 탄 사람 같은 그날의 분위기를 차량 데이터로 함께 저장합니다.

## 핵심 기능 (P0 = 12/3 PT 데모 범위)

| ID | 기능 | 설명 | 등급 |
| --- | --- | --- | --- |
| F-01 | 캡슐 묻기 | 음성 명령·핸들 버튼으로 최대 30초 녹음 | P0 |
| F-02 | 분위기 태그 | 녹음 순간의 차량 상태(와이퍼, 전조등, 탑승 인원 등)로 태그 자동 생성 | P0 |
| F-03 | 경로 예고 | 출발 시 오늘 경로에 묻힌 캡슐 안내 | P0 |
| F-04 | 접근 알림 | 캡슐 1.2km 앞에서 열기 제안 | P0 |
| F-05 | 캡슐 재생 | 내레이션 + 원본 목소리, 안전 신호에 자동 일시정지 | P0 |
| F-06 | 편지 캡슐 | 열리는 날짜를 잠근 캡슐 | P0 |
| F-07 | 추억 경로 | 지난 여행의 캡슐 지점을 경유지로 내비 설정 | P0 |
| F-08 | 여행 앨범 | 여행 시작·끝을 감지해 캡슐을 묶음 | P1 |
| F-12 | 그날처럼 | 재생 시 창문·온도·조명 재현 (차량 제어 API) | P2 |

전체 명세는 [`docs/feature-spec.html`](docs/feature-spec.html), 기획서는 [`docs/proposal.html`](docs/proposal.html)에 있습니다. (내려받아 브라우저로 열어 보세요.)

## 사용 SDK

| SDK | 용도 | 상태 (2026.11 기준) |
| --- | --- | --- |
| Vehicle SDK | 분위기 태그, 안전 신호, 여행 감지 | 사용 가능 |
| NaviHelper | 경로 예고, 접근 판단, 추억 경로 | 사용 가능 |
| FusedLocation | 근접 알림 | 준비 중 → NaviHelper로 대체 |
| STT / TTS | 받아쓰기, 내레이션 | 준비 중 → 미리 녹음한 안내 음성 |
| Gleo Interface | “타임캡슐, 묻어줘” 음성 호출 | 확인 필요 |

## 개발 환경

- Android Studio, Kotlin, Gradle 8+
- minSdk 28, Pleos Connect 에뮬레이터 (API 34) + Virtual Console
- Maven: `ai.pleos.playground:Vehicle` (`https://nexus-playground.pleos.ai/repository/maven-releases/`)
- 문서: https://document.pleos.ai
