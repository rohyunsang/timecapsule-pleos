타임캡슐 기능 기획서

Pleos Connect 차량 앱 “타임캡슐”의 기능 단위 명세입니다. 기능마다 트리거, 동작, 쓰는 데이터, 예외를 정했고, 12/3 PT 데모 범위(P0)를 먼저 표시했습니다. 화면은 UI/UX 캔버스의 01~06번과 짝을 이룹니다.

범위와 우선순위기능 목록기능 상세태그·알림 규칙상태 흐름데이터 모델비기능 요구사항역할 분담

01범위와 우선순위

등급의미기준
P011/15 접수 영상과 12/3 PT 데모에 반드시 동작지금 쓸 수 있는 Vehicle SDK(조회)·NaviHelper만으로 구현 가능
P1PT 전까지 넣으면 점수가 오르는 기능설명회 답변에 따라 SDK가 열리면 구현
P2비전. 발표 슬라이드·영상으로 제시차량 제어 API, 클라우드 계정 등 공모전 기간 밖 의존

03기능 상세

F-01캡슐 묻기P0
트리거
“타임캡슐, 묻어줘”(Gleo 연동 시), 핸들 음성 버튼, 홈의 묻기 버튼(정차 시)
동작
시작 알림음 → 최대 30초 녹음 → 종료 알림음 → F-02 태그 생성 → 저장 → “○○ 캡슐을 묻었어요” 음성 확인
종료
“그만” 발화, 끝내기 버튼, 30초 도달, 안전 신호 발생(녹음분은 저장할지 묻지 않고 저장)
데이터
마이크 오디오, 위치(위도·경도), NaviHelper 목적지 이름, 시각
예외
마이크 권한 없음 → 안내 후 종료. 3초 미만 녹음 → 저장하지 않음. 위치 없음 → 마지막 위치로 저장하고 “위치 불확실” 표시
F-02분위기 태그P0
트리거
F-01 녹음 시작 시점의 차량 상태 스냅샷
동작
각 도메인 값을 규칙표(04장)로 태그화, 최대 5개. 내레이션 문장 템플릿에 넣을 순서로 정렬(시간 → 날씨 → 사람 → 장소)
데이터
Wiper, Light, Seat, HVAC(외기온도), Window, Door, DrivingMode, Toll, CarInfo, Odometer
예외
값을 못 읽은 도메인은 태그를 만들지 않음. 원시값은 함께 저장해 나중에 규칙이 바뀌어도 다시 계산
F-03경로 예고P0
트리거
NaviHelper 경로 안내 시작
동작
경로 선(polyline)에서 300m 안에 있는 캡슐을 찾아 “오늘 길에 캡슐이 n개 묻혀 있어요” 1회 안내. 홈 카드에 가장 오래된 캡슐과 남은 거리 표시
예외
잠긴 편지 캡슐(날짜 전)은 존재만 알리고 내용은 숨김. 받는 사람이 아니면 아예 알리지 않음(P1)
F-04접근 알림P0
트리거
캡슐까지 남은 거리 1.2km 이하. FusedLocation 근접 알림이 열리면 그것으로, 아니면 NaviHelper 남은 거리로 판단
동작
알림음 + 카드(화면 05) + 음성 “○년 전, ○○ 캡슐이 있어요”. 선택지 “들려줘”/“다음에”, 음성으로도 응답
억제
내비 음성 안내 중, 방향지시등 켜짐, 안전 경고 중에는 띄우지 않고 해제 후 10초 뒤 표시. 같은 캡슐은 하루 1회
예외
“다음에” 또는 무응답 10초 → 다음 정차(P단) 때 홈에 다시 표시
F-05캡슐 재생P0
동작
내레이션(TTS 또는 미리 녹음된 문장 조합) → 원본 목소리. 화면 06에 날짜·장소·탑승 자리 표시
일시정지
Safety 경고, 급제동(Brake), 방향지시등(TurnSignal), 내비 음성 안내. 해제 2초 뒤 자동 재개
조작
처음부터, 일시정지, 앨범에 담기. 음성 “다시”, “멈춰”
F-06편지 캡슐P0
트리거
정차 중 홈 → 편지 메뉴(화면 02). 주행 중에는 만들 수 없음
입력
받는 사람(P1: 가족 프로필), 열리는 날(1년 뒤 / 10년 뒤 / 기념일 / 직접), 장소(현재 위치, 반경 300m), 녹음
동작
열리는 날 전에는 F-03·F-04에서 내용 숨김. 날짜가 지나고 받는 사람이 그 길을 지나면 일반 캡슐처럼 열림
예외
받는 사람 구분 API가 없으면 날짜 잠금만 제공
F-07추억 경로P0
트리거
앨범의 “이 길 다시 달리기”(화면 03) 또는 음성 “그때 그 길로 가줘”
동작
앨범의 캡슐 지점을 시간순으로 골라 NaviHelper 경유지로 설정(경유지 수 제한은 SDK 확인). 주행 중 각 지점에서 F-04 실행
F-08여행 앨범P1
시작 감지
내비 안내 시작 또는 톨게이트 진입
종료 감지
시동 종료 + 사이드미러 접힘, 또는 내비 도착 후 6시간 이상 주행 없음
동작
그 사이 캡슐을 묶고, 달린 거리(Odometer 차이)·탑승 인원·경로를 기록. “캡슐 n개를 앨범으로 묶었어요” 안내
F-09도착 순간 제안P1
트리거
내비 도착 + P단 + 문 열림, 그리고 캡슐이 없는 장소(반경 300m)
동작
“도착 한마디 남길까요?” 1회. 대답 없으면 넘어감. 하루 최대 2회
F-13개인정보 관리P0
규칙
명시적 호출로만 녹음. 상시 청취 없음. 녹음 시작·끝 알림음은 끌 수 없음
설정
캡슐 개별·전체 삭제, 저장 위치(차량만 / 계정 동기화), 도착 제안 끄기
차량 판매
“차량에서 모두 지우기” 실행 시 기기 데이터 삭제, 계정 사본만 유지(P2)

내레이션 템플릿

{경과}년 전 {오늘?}, {날씨/시간 태그}. {인원 태그} 이 길을 지나며 남긴 목소리예요.

예: “18년 전 오늘, 비 오던 밤. 셋이서 이 길을 지나며 남긴 목소리예요.” 1년 미만이면 “○달 전”, 같은 날짜면 “오늘”을 넣습니다.

05상태 흐름 (주행 중)

주행 중 앱은 다섯 상태만 가집니다. 안전 신호는 어느 상태에서든 일시정지로 보냅니다.

06데이터 모델

엔티티필드비고
Capsuleid, createdAt, lat, lng, radiusM(300), placeName, audioPath, durationSec, transcript?, tags[], rawVehicleState{}, tripId?, carModel, odometerKmrawVehicleState는 태그 재계산용
LetterLockcapsuleId, openAfter(date), recipientProfileId?없으면 일반 캡슐
Tripid, startAt, endAt, startOdometer, endOdometer, occupants, routePolyline?, capsuleIds[]routePolyline은 앨범 켠 경우만
Profileid, name, relation운전자 구분 API 확인 후(P1)
NotifyLogcapsuleId, date, result(played / later / ignored)하루 1회 제한 판단

저장은 기기 안 Room(SQLite) + 오디오 파일. 계정 동기화(P2)는 공모전 범위 밖입니다.

07비기능 요구사항

  • 주행 제한: Distraction Optimization을 선언하고, 주행 중 화면은 04·05·06번만 씁니다. 스크롤·키보드 입력 없음, 버튼 높이 72px 이상.
  • 응답 속도: 버튼 누른 뒤 녹음 시작까지 0.5초 안, 태그 생성 1초 안(목표치).
  • 오프라인: 네트워크 없이 모든 P0 기능 동작.
  • 환경: Android Studio, minSdk 28, Pleos Connect 에뮬레이터(API 34) + Virtual Console, Kotlin.
  • 권한: 사용하는 Vehicle 도메인의 읽기 권한만 선언. 제어 권한(CONTROL_CAR_*)은 F-12 구현 때만.
  • 제출: APK는 apk/팀명_타임캡슐_release.apk.
