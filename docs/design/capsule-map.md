# 캡슐 지도 UI 개선

2026-11-04에 공식 레퍼런스를 확인하고 적용했습니다. 커스텀 Compose/MapLibre 화면이며 Android for Cars 템플릿 구현이나 차량 안전 인증을 의미하지 않습니다.

## 참고와 적용

- [Google Place List (map)](https://developers.google.com/cars/design/create-apps/apps-for-drivers/templates/place-list-map-template): 장소 마커는 텍스트·아이콘·이미지를 사용할 수 있습니다. 관련 위치를 간결하게 표시하는 방향을 참고해 이름 아바타와 상태 배지로 바꿨습니다.
- [Google Map + Content](https://developers.google.com/cars/design/create-apps/apps-for-drivers/templates/map-content-template): 지도와 해당 장소의 관련 콘텐츠·주요 동작을 연결하는 구성을 참고했습니다. 상시 가로 목록과 큰 하단 지도 조작 버튼을 제거하고, 지도 내부 조작 버튼과 선택한 한 건의 카드로 분리했습니다.
- [Pleos 내비게이션 개발 가이드](https://document.pleos.ai/en/docs/pleos-only/vehicle-app-developer-guide/navigation-app-development-guide): 경로 변경은 사용자의 명시적 선택을 통해 요청합니다. 기존 NaviHelper 연동을 유지하며 내비게이션 앱으로 분류하거나 자동 안내를 시작하지 않습니다.

## 상태와 동작

| 상태 | 지도 표시 | 선택 후 확인 |
| --- | --- | --- |
| 내가 남겼지만 아직 수집하지 않음 | 짙은 회색 테두리와 잠금 | 목적지 길 안내 |
| 개봉일 전 | 잠금, 상세의 개봉 대기·날짜 | 목적지 길 안내 |
| 현장 수집 완료 | 초록 테두리와 재생 | 음성 재생 |
| 같은 장소에 여러 캡슐 | 개수 배지, 혼합 상태면 잠금·재생 모두 | 개별 선택 후 해당 확인창 |

이름은 내 캡슐의 경우 ‘나’, 친구 캡슐은 이름 첫 글자이며 여러 소유자의 같은 장소는 ‘모음’으로 표시합니다. 색만으로 상태를 전달하지 않습니다. 현재 Profile/Friend에는 사진 URL과 업로드·동기화 경로가 없으므로 실제 프로필 사진은 이번 범위에 포함하지 않습니다. 추후 사진 데이터와 로딩·실패 처리를 추가하면 원형 아바타 안에 사진을 표시할 수 있습니다.

지도에는 유효한 내 위치 기록과 직접 수집한 친구 캡슐만 표시합니다. 임시보관·불확실 좌표·전달받은 음성·미수집 타인 캡슐은 제외합니다. 기존 CollectedMapData의 실제 수집 판정은 변경하지 않고 별도 CapsuleMapData에 표시 정책을 둡니다. 개봉일 제한은 수집 여부보다 우선합니다.

상단 목록 아이콘으로 전체 목록을 열 수 있으며 지도 오류 때에도 목록을 사용할 수 있습니다. 지도 마커 선택만으로 경로 요청이나 재생을 실행하지 않습니다. 확인 후 기존 DriveController가 DB·차량 상태·권한을 다시 확인합니다. 지도 타일 공급자, 출처 링크, 현재 위치 유효성, 주차 탐색 제한은 유지합니다.

## 검증

- `:app:testDebugUnitTest`: 총 82개 테스트 통과. 새 표시 범위·날짜 경계·혼합 그룹·이름 대체값 테스트 6개를 포함합니다.
- `:app:assembleDebug :app:lintDebug`: 통과했습니다.
- Pleos 에뮬레이터 사용자 10에 APK를 설치했습니다. 잠긴 마커의 길 안내 확인창, 열린 마커의 재생 확인창, 혼합 그룹의 개별 선택창을 직접 확인했습니다. 넓은 화면과 실제 분할 화면에서 지도·선택 카드·조작 버튼을 확인했습니다.
- 이번 UI 검증에서 확인창을 취소했으며 실제 경로 완료나 Firebase 친구 음성 재생을 새로 검증했다고 주장하지 않습니다. 기존 임시 캡슐과 원본 데이터를 보존했습니다.
