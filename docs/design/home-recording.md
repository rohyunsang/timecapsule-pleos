# 홈과 녹음 화면 개선

2026-11-04 사용자 요청에 따라 적용했습니다.

## 공식 참고

- [Android Automotive 크기 가이드](https://developers.google.com/cars/design/automotive-os/design-system/sizing): 최소 76dp 터치 영역을 참고했습니다. 최근 목록 진입은 88dp, 녹음 버튼은 176dp, 하단 완료·취소는 기존 큰 터치 크기를 사용합니다.
- [Android Automotive 타이포그래피](https://developers.google.com/cars/design/automotive-os/design-system/typography): 정보 위계와 짧게 읽을 수 있는 구성을 참고했습니다. 녹음 시간은 큰 고정폭 숫자, 장소·남은 시간은 보조 정보로 표시합니다.
- [Apple 음성 메모 녹음](https://support.apple.com/en-au/guide/iphone/iph4d2a39a3b/ios): 녹음 시간과 입력 파형을 분리해 보여주는 흐름을 참고했습니다. 일시정지 기능을 새로 추가하지는 않았습니다.

## 적용

홈의 넓은 화면은 전체 너비 헤더 아래 녹음 패널과 최근 캡슐 목록을 배치합니다. 좁은 화면은 단일 열과 하단 메뉴를 유지합니다. 목록에는 기간·길이·수집 상태를 표시합니다.

녹음 버튼은 반투명 상부와 빨간 하부, 이음선·잠금 장식·마이크가 있는 구형 뽑기 캡슐입니다. 녹음 화면의 같은 캡슐은 기존 Recorder 입력값을 100ms마다 읽고 180ms 보간으로 최대 8% 확대합니다. 빛의 크기·불투명도와 최근 48개 입력 막대가 소리 크기에 반응합니다. 임의 파형이나 반복 진동을 만들어 실제 입력처럼 보여주지 않습니다. animate가 false인 주행 제한 상태에서는 파형 갱신과 캡슐 움직임을 멈춥니다.

녹음 화면의 날씨 배경을 없애고 시간·장소·파형·남은 시간을 단순한 패널에 배치했습니다. 완료 버튼을 빨간색으로 강조하고 ‘녹음 완료 · 저장’으로 명시했습니다. 3초 최소 길이, 자동 무음 저장, 취소 및 기존 차량 안전 정책은 유지합니다.

## 검증

- debug 빌드와 lint를 통과했습니다.
- 에뮬레이터의 넓은 화면과 분할 화면에서 홈 및 녹음 화면을 확인했습니다. 구형 버튼과 녹음 중 캡슐 표시도 확인했습니다.
- 짧게 녹음 화면을 열고 취소했으며 기존 캡슐 13개를 유지했습니다. 에뮬레이터 입력은 무음이어서 실제 발화에 따른 시각적 진폭 변화는 별도 마이크 입력 검증이 필요합니다.
- 제품은 커스텀 Compose UI이며 공식 차량용 템플릿 준수 인증을 의미하지 않습니다.
