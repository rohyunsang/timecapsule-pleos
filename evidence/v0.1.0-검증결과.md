# 타임캡슐 차량 앱 검증 결과

2026년 11월 1일, 공식 Pleos Connect 2.1.0 ARM64 에뮬레이터(API 34)에서 확인했습니다. 물리 차량을 시험한 결과는 아닙니다.

## 빌드와 설치

- Kotlin 네이티브 앱이며 패키지는 `io.timecapsule.vehicle`, 버전은 `0.1.0`입니다.
- Vehicle 2.3.2와 FusedLocation 1.1.3을 공식 Maven 저장소에서 받아 컴파일했습니다.
- `:app:testDebugUnitTest :app:lintDebug :app:assembleRelease :app:assembleDebug`가 통과했습니다. 단위 테스트 4개, 실패 0개입니다.
- Android Lint는 오류 0개, 경고 2개입니다. Pleos API 34에 맞춘 targetSdk 34와 한국어 UI 문자열 조합에 관한 경고입니다. Gear API의 deprecated 컴파일 경고도 남아 있습니다.
- 로컬 전용 키로 서명한 release APK의 v3 서명을 검증했습니다. `debuggable=false`입니다.
- release APK를 자동 권한 부여 없이 설치하고 실제 시스템 권한 대화상자로 위치·Pleos 위치·알림·마이크를 허용했습니다.
- 설치한 APK와 전달 파일의 SHA-256이 일치합니다: `c93625ebd6fe3df1c1fea579fc3f248df2e965bad21987726bb7ca7db981743d`.
- release 실행에서 타임캡슐 프로세스의 fatal exception은 관측하지 않았습니다.

## 주행 중 화면과 소리

Pleos는 이 앱의 화면에 ‘주행 중에는 사용할 수 없습니다’를 표시합니다. 이 제한을 우회하지 않았습니다. 사용자가 P단에서 켜 둔 foreground 청취는 화면이 막혀도 위치 진입 시 오디오를 재생했습니다. 주행 중 화면 조작으로 녹음·설정을 제공한다는 의미는 아닙니다. 실제 차량 및 마켓 심사에서 허용되는 청취 정책은 별도 확인이 필요합니다.

## 확인한 권한 주의점

이 에뮬레이터에서 `pleos.car.permission.FUSED_LOCATION`은 dangerous 런타임 권한입니다. Android의 정확한 위치 권한만으로는 사용할 수 없습니다. 앱은 두 권한을 모두 요청하고 검사합니다. 현재 Pleos 이미지의 권한 대화상자에는 이 SDK 권한이 ‘알 수 없는 작업’으로 표시됐습니다. 해당 권한의 제공 패키지가 공식 `ai.pleos.playground.service.location.fused`인 것을 확인했습니다.

## 한계와 후속 확인

- 오디오 입력을 비활성화한 에뮬레이터에서 녹음·파일·재생 파이프라인을 검사했습니다. 사람의 실제 음성, 실차 마이크 품질, 스피커 청감은 검증하지 않았습니다.
- 별도 검증 앱의 오디오 포커스 요청은 실제 내비 앱·전화 통화·모든 차량 경고를 대신하는 전수 검사가 아닙니다.
- FusedLocation confidence 값의 정확도 단위와 도로 단위 위치 판정은 미확인입니다. 현재는 좌표·타임스탬프·수신 시간·거리 조건을 검사합니다.
- 가족 계정·상호 팔로우·동기화·차량 간 이전·NaviHelper·Gleo·STT·TTS·분위기 태그·ADAS 전체 신호는 후속 구현 범위입니다.
- 실차 설치 권한, 차량별 SDK 버전과 오디오 라우팅, Pleos App Market 승인은 검증하지 않았습니다.
- 소스는 독립 작업 디렉터리에 있습니다. 기존 Git 저장소나 원격이 없어 커밋·PR·push·merge는 수행하지 않았습니다. 공모전 이메일이나 마켓 제출도 하지 않았습니다.
