# 타임캡슐 0.3.0 검증 결과

2026년 11월 2일. Pleos Connect 2.1.0 / Android 34 ARM64 에뮬레이터에서 시험했습니다. 실제 차량에서는 시험하지 않았습니다.

## 통과

- Kotlin debug/release 빌드, 8개 단위 테스트, Lint 0 errors / 5 warnings, release APK v3 서명 검사.
- 출발 전 기록 준비만으로는 녹음하지 않음. 준비하지 않은 기록 요청 거절.
- D단 + 내비 앱 전면에서 신뢰된 MediaSession 커스텀 액션으로 백그라운드 녹음 시작.
- 15초 자동 저장, 이동 중에도 시작 위치 보존, 중복 요청이 타이머를 늘리지 않음.
- 별도 도구의 NAVIGATION 오디오 포커스가 녹음을 중단하면 임시보관, 안내 종료 후 자동 녹음 없음.
- 명시적인 취소가 현재 파일만 폐기. 일반 PLAY로 녹음되지 않음. 전용 RECORD 키 이벤트로 녹음 시작.
- 방향지시등으로 임시보관. STOP으로 microphone/location foreground 세션 종료. 이번 시험이 만든 녹음 3개를 UI로 삭제하고 이전 ID 목록 유지.
- 이전 0.2.0에서는 내비 전면 청취·일시정지·수동 재개·위치 이탈 후 지속·미래 캡슐 우회 거절·자동 연속 청취 방지를 확인했습니다. 해당 시험 로그를 역사적 근거로 함께 보관합니다.

## 최종 release 재검증 상태

0.3.0 release APK 설치는 성공했습니다. 재검증 초반 내비 이동과 자동 재생 없는 도착 대기까지 확인했습니다. 이후 테스트의 목록 단정이 기존 캡슐을 허용하지 않아 실패했고, 단정을 수정한 재실행 중 에뮬레이터 연결이 종료됐습니다. 따라서 현재 최종 release 전체 시나리오를 통과했다고 선언하지 않습니다. debug에서 확인한 전체 기록 흐름과 구분합니다.

## 해석과 한계

- 내비 앱은 초기화 지연 화면이었습니다. 실제 지도 경로 안내와의 통합은 미검증이며, 오디오 우선권은 별도 NAVIGATION 유형 도구로 검증했습니다.
- Gleo 스키마와 권한 보호 수신기는 구현했습니다. 스키마 심사, Gleo 실제 발신 권한·콜백 수신 호환성, 음성 인식부터 녹음까지는 미검증입니다.
- RECORD 시험은 에뮬레이터 키 이벤트이며 실제 핸들 버튼 매핑 증거가 아닙니다.
- 호스트의 실제 사람 목소리를 녹음하지 않았습니다. 파일 생성·좌표·상태 전환 검증이며 실차 마이크 음질·음성 인식 검증이 아닙니다.
- 위치 100m는 동일 도로를 보장하지 않습니다. 10초 이내 위치도 고속 주행 시 충분히 정확하지 않을 수 있습니다. 도로 매칭·timestamp/accuracy 검증이 필요합니다.
- 모든 ADAS·급제동 신호에 대응하지 않습니다. 사람 대상 운전 안전성 연구나 인증 결과가 아닙니다.
- Lint의 exported MediaBrowserService 경고는 표준 외부 연결 서비스에 대한 경고입니다. onGetRoot의 UID/서명/시스템 미디어 권한 검사와 커스텀 기록 액션의 제어자 검사를 구현했습니다. target API 관련 경고는 대상 Pleos 이미지와 호환성 재검토가 필요합니다.
- 원래 작업 폴더는 Git 저장소가 아니므로 커밋·PR·원격 배포는 없었습니다. 공모전 접수도 하지 않았습니다.

재검증 환경 복구도 emulator GPU/context 오류로 종료됐습니다. 테스트 probe와 합성 ux-v02 fixture는 에뮬레이터 저장소에 남아 있을 수 있습니다. 이번 0.3 기록 시험의 3개 녹음은 삭제 확인했으며, 이전 항목을 강제로 지우지는 않았습니다. 최종 APK 자체에는 fixture·probe가 포함되지 않습니다.
