# 타임캡슐 제출 준비 안내

작성 기준: 2026년 11월 2일. 이메일 접수는 실행하지 않았습니다.

## 준비한 자료

- 타임캡슐_공모전_접수양식.docx: 공식 양식의 기획 항목을 작성했습니다. 참가 구분, 팀명, 인적사항, 구성원, 동의·서명·날짜는 비워두었습니다.
- 타임캡슐_기획서.md: 동일한 기획 내용의 편집용 원고입니다.
- apk/타임캡슐_release.apk: Kotlin 네이티브 차량 앱입니다. Pleos 에뮬레이터에서 실행과 SDK 연동을 검증했습니다. 실차 및 App Market 승인은 별도입니다.
- native-source.zip: 네이티브 소스, 빌드·실행 안내, 검증 결과입니다.
- prototype.zip: 브라우저에서 실행하는 프로토타입과 실행 안내입니다. APK가 아닙니다.

## 직접 작성할 항목

참가 단위·부문, 팀명 또는 개인 성명, 대표자 연락처와 인원, 구성원 정보, 작성일, 참가자 각자의 동의·서명·날짜를 기입하세요. 동의 여부와 서명은 타인이 대신 선택하지 않습니다. 심사 자료인 앱 프로젝트 소개에는 참가자 개인정보를 추가하지 마세요.

## 제출 절차

공식 접수 마감은 2026년 11월 15일 23:59 KST입니다. 작성·서명한 양식을 appdevchallenge@hyundai-partners.com으로 제출합니다. 팀 참가 시 팀원 전원을 CC에 포함합니다. 메일 제목은 `[차량용 앱 개발 공모전] 팀명(개인은 성명)_대표자명` 형식입니다.

프로토타입은 선택 참고자료입니다. release APK는 준비했으며 공개 저장소와 영상 링크는 아직 발급하지 않았습니다. GitHub 저장소·영상 항목을 준비한 것으로 기재하지 마세요. 웹 소스 ZIP이 GitHub+APK 가산점 제출을 대체한다고 가정하지 않습니다. 2차 PT에는 실제 동작 앱이 필요합니다.

본 DOCX의 참고자료 항목은 현재 준비 상태를 설명합니다. 실제 발송 전 첨부한 화면 자료·영상·접근 가능한 링크만 남기고 문장을 확정하세요. ZIP을 첨부할 경우에는 운영 측의 수신·실행 가능 여부를 확인하는 것이 좋습니다.

## 시연 녹화 구성안

1. 0~10초: 차량 홈과 주차 중 사전 청취 설정.
2. 10~25초: 주행 상태 전환, 장소 진입, 실제 오디오 재생.
3. 25~40초: 내비 유형 오디오 포커스 개입과 수동 재개.
4. 40~55초: 장소 이탈 후 열린 캡슐의 완료 허용과 사용자 종료.
5. 55~75초: D단·내비 전면에서 기록 명령, 15초 자동 저장, 내비 포커스로 중단된 녹음 임시보관.

웹 시연 영상에는 모의 차량·위치 입력임을 표시하고, 네이티브 시연에는 Pleos Connect 에뮬레이터와 Virtual Console의 신호를 사용한 시험임을 표시합니다. 에뮬레이터에서의 무음 마이크 입력 시험을 실제 가족 음성이나 실차 음질 검증으로 소개하지 않습니다. 합성 안내 음성을 실제 가족의 녹음처럼 소개하지 않습니다.

## 0.3.0 주행 UX 변경

현재 제출 APK는 0.3.0입니다. 네이티브 앱과 기획서는 장소 진입 후 한 캡슐의 일회 청취, 미디어 키 제어, 중단 위치 보존 및 주행 중 15초 기록을 반영합니다. prototype.zip은 이전 브라우저 시안이며 일부 정책이 다릅니다. 최신 동작 증거는 native-source.zip의 evidence/v0.3.0을 참조하세요. 에뮬레이터 기본 내비가 실행 지연 화면을 표시하여 실제 경로 안내와의 통합은 미검증입니다. 별도 오디오 포커스 도구와 시스템 미디어 키로 확인한 범위를 구분하여 발표하세요.

Gleo 연동 코드와 assets/schema.json은 포함했지만 스키마 심사·실제 음성 호출은 완료하지 않았습니다. 기록 시험은 서명된 테스트 제어 앱의 MediaSession 커스텀 명령과 에뮬레이터 전용 RECORD 키 입력으로 진행하며, 실물 핸들 버튼 검증으로 소개하지 않습니다. 일반 PLAY 키는 녹음을 시작하지 않습니다.
