# 타임캡슐 공모전 기획서

작성일 2026년 11월 2일

## 앱 한 줄 소개

타임캡슐은 여행 중 남긴 짧은 목소리를 장소와 개봉일에 묶어 두고, 같은 길을 다시 지날 때 운전자와 가족이 차량 안에서 들을 수 있도록 설계한 Pleos Connect 앱입니다.

## 기획 배경

가족 여행에서 기억하고 싶은 순간은 목적지뿐 아니라 이동 중에도 생깁니다. 아이의 한마디, 부모의 웃음, 함께 바라본 풍경은 사진만으로 남기기 어렵습니다. 일반 음성 메모는 기록을 직접 찾아야 하고, 여행 사진은 목소리와 그때의 이동 맥락을 함께 전달하기 어렵습니다.
주요 고객은 어린 자녀와 여행하는 가족이며, 커플과 혼자 여행하는 운전자를 다음 대상으로 설정했습니다. 핵심 고객 요구는 ‘지금의 목소리를 간단히 남기고, 의미 있는 장소에서 다시 만나고 싶다’입니다. 아직 사용자 인터뷰로 검증한 결과는 아니며 초기 가족 사용자 실험으로 확인할 가설입니다.
타임캡슐은 검색과 화면 탐색 대신 차량의 이동 맥락이 기억을 다시 만나는 계기가 되도록 합니다. 녹음은 명시적으로 시작하고, 듣기는 주차 중 선택한 설정과 개봉 조건에 따라 동작합니다. 가족의 원본 목소리를 AI로 재구성하거나 고인의 음성을 복제하지 않습니다.

## 앱 주요 기능 및 차량 특화 요소

① 캡슐 묻기: 출발 전에 동승자 동의와 마이크 권한을 확인하고 이번 주행의 기록을 준비합니다. 주행 중 명시적인 기록 명령을 보내면 내비 화면을 유지한 채 최대 15초를 녹음하고, 시작한 위치에 자동 저장합니다. 제목·수신자·날짜를 주행 중 묻지 않습니다. 내비 안내나 방향지시등으로 중단되면 임시보관하며, 다음 주차 때 정리합니다. Gleo 음성 호출은 연동 코드·스키마를 준비했으며 실제 호출과 전용 핸들 버튼 매핑은 별도 검증 대상입니다.
② 길 위에서 듣기: 기본 꺼짐인 주행 청취를 주차 중 사용자가 켭니다. 지정 장소 진입, 개봉일 도래, 수신 권한, 유효한 위치를 모두 확인한 뒤 청취를 제안하거나 재생합니다. 화면 탐색과 편집은 주행 중 제한합니다. 내비 안내 등이 개입하면 재생 위치를 보존해 일시정지하고, 사용자의 미디어 재생 조작으로 이어 듣습니다. 자동으로 재개하지 않습니다. 현장에서 열린 한 캡슐은 5분 이내 현재 세션에서 마저 들을 수 있고 영구 해제되지는 않습니다.
③ 편지 캡슐과 공유: 자신, 특정 가족, 서로 수락한 친구를 대상으로 공유합니다. 가족 계정과 상호 팔로우는 별도로 관리합니다. 다른 사람이 공유받아도 같은 장소와 날짜 조건을 충족해야 들을 수 있으며, 앨범 링크는 원본 음성을 우회 제공하지 않습니다.
④ 추억 경로와 여행 앨범: 캡슐 장소를 차량 내비에 전달하고 하루의 기록을 모읍니다. 내비 경로에 포함됐다는 사실만으로 도착을 판정하지 않습니다.
차량 특화 가치는 차량 위치와 주행 상태, 오디오 우선순위가 하나의 청취 경험에 결합된다는 점입니다. 지원되는 와이퍼·조명 등의 상태는 분위기 태그의 보조 자료로만 사용하며, 날씨·탑승 인원·동승자 신원을 확정하지 않습니다. 창문·공조·조명을 재현하는 ‘그날처럼’은 차량 제어 승인이 필요한 장기 구상입니다.

## 주요 사용 시나리오

대표 시나리오는 2027년과 2045년을 배경으로 한 미래 사용 예시입니다.
1. 2027년 여름, 가족이 강릉으로 향합니다. 출발 전에 기록을 준비해 둔 아빠가 바다가 보이는 길에서 ‘타임캡슐, 지금 남겨줘’라고 요청합니다. 알림음 뒤 아이의 ‘바다 냄새 나!’라는 목소리를 녹음하고 호출한 위치에 자동 저장합니다. 목적지에 주차한 뒤 딸을 수신자로 지정하고 2045년 8월 15일을 개봉일로 고릅니다. 음성 호출·수신자 지정은 목표 서비스 시나리오이며, 현재 APK의 검증 범위와 구분합니다.
2. 2045년, 성인이 된 딸이 같은 길을 여행합니다. 출발 전 주행 청취를 켜고 수신한 캡슐을 확인합니다. 계정 이전과 장기 보관이 제공되는 미래 서비스 상황을 가정한 이야기이며, 현재 18년 보관을 보장한다는 의미는 아닙니다.
3. 차량이 지정 구역에 들어오면 실제 위치의 최신성·정확도와 개봉 조건을 검증합니다. 조건이 맞으면 짧은 안내와 목소리를 들려주며, 내비 화면을 유지하고 차량 미디어 제어로 듣도록 합니다.
4. 내비 안내나 통화가 시작되면 캡슐을 멈춥니다. 안내가 끝나도 자동으로 이어 틀지 않으며, 사용자의 재개 요청 시 조건을 다시 검사합니다. 방문으로 열린 한 캡슐은 장소를 지나도 개봉 후 5분 이내 현재 세션에서 마저 들을 수 있습니다. 원격 영구 개봉을 허용하지 않으며, 재생을 위해 감속·정차·우회를 요구하지 않습니다.
5. 여행 종료 후 주차 중 앨범을 확인합니다. 가족 초대와 공유는 상대의 수락 및 각 캡슐의 권한 설정을 거칩니다.

## 개발 계획

현재 구현 수준
Kotlin 네이티브 앱 0.3.0과 서명한 release APK를 준비했습니다. Pleos Vehicle 2.3.2와 FusedLocation 1.1.3을 연결합니다. 출발 전 기록 준비와 주행 중 최대 15초 녹음, 시작 위치에 자동 저장, 공개일 선택, 장소 기반 개봉, 삭제를 구현했습니다. 내비 화면과 D단을 유지한 채 별도 기록 명령을 수신합니다. 내비 포커스나 방향지시등으로 중단되면 앞부분을 임시보관하고 다음 주차 때 저장·삭제합니다. 현재는 본인이 이 기기에서 만든 캡슐을 다룹니다.
내비와 함께 쓰는 청취 UX
출발 전에 ‘알림 후 버튼으로 듣기’ 또는 ‘도착하면 자동 듣기’를 명시적으로 선택합니다. 준비 후 내비 앱을 별도 작업으로 열며, 재생이 앱 화면을 강제로 띄우지 않습니다. MediaBrowserService와 MediaSession으로 재생·일시정지·건너뛰기·종료를 연결했습니다. 내비 오디오 우선권 개입이나 방향지시등에는 위치를 보존해 멈추며 자동 재개하지 않습니다. 현장에서 열린 한 캡슐은 5분 이내에 마저 듣도록 하여 구역 이탈을 이유로 감속할 필요를 줄였습니다.
위치 및 차량 제한
반경 100m 진입과 개봉일을 확인하고, 자동 감지는 150m 밖을 거친 재방문과 서로 다른 위치 샘플 2회를 요구합니다. 같은 자리에서 켜거나 방금 녹음한 캡슐은 자동으로 재생하지 않습니다. 기어는 5초, 위치는 10초 이내 정보만 사용하며 CarUxRestrictions도 직접 구독합니다. 상태가 불명확하면 새 청취를 시작하지 않고 재생을 보류합니다. 위치의 confidence 단위와 도로 매칭은 미확인으로, 현재는 동일 도로가 아닌 저장 좌표 주변을 판정합니다.
세션과 개인정보
청취와 주행 기록 준비의 기본값은 꺼짐입니다. 마이크 foreground service를 주차 중 시작하지만 기록 명령 전에는 MediaRecorder를 열지 않습니다. 일반 재생 키로 녹음하지 않습니다. 사용자 종료, 2시간 만료 또는 15분 연속 주차 시 청취와 백그라운드 위치 대기를 종료합니다. 프로세스 재시작 후 자동 복구하지 않습니다. 시간·거리 수치는 초기 제품 설정이며 안전 인증 기준이 아닙니다. 음성과 위치는 앱 내부 저장소에 보관하며 클라우드 백업과 자동 기기 이전을 제외했습니다. 녹음 전 동승자 동의를 확인합니다. START/SAVE/CANCEL 기록 명령과 Gleo schema.json을 구현했으며 외부 수신은 시스템 미디어 제어 권한으로 보호합니다. Gleo 심사와 실제 발신 권한 호환성은 미확인입니다.
검증 및 후속 범위
공식 Pleos 2.1.0 에뮬레이터에서 차량·위치·주행 제한 콜백과 시스템 미디어 키 동작을 확인했습니다. 내비 앱 전면에서 청취와 D단 백그라운드 녹음, 별도 도구의 내비 유형 오디오 포커스 개입을 시험합니다. 실제 차량의 녹음 허용, 마이크 점유 충돌과 안전성은 별도 검증합니다. 기본 내비가 실행 지연 화면을 보여 실제 지도 경로 안내, 실물 핸들 버튼과 실차 음질은 검증하지 못했습니다. 오디오 시나리오에는 합성 무음 파일을 사용했으며 사람 대상 운전 안전 시험은 아닙니다.
가족 계정·팔로우·서버 동기화·차량 간 이전·NaviHelper 경로 전달·분위기 태그·Gleo 실제 음성 호출·STT·TTS·ADAS 전체 대응은 후속 범위입니다. 오디오 중심 앱 분류와 하위 카테고리, 차량 미디어 센터 노출 및 마켓 허용은 별도 확인합니다. 11월 2~12일에 운전자 시뮬레이터 평가와 플랫폼 호환성을 보강하고, 13~15일에 제출 자료를 정리할 계획입니다.

## 기대효과 및 발전 가능성

타깃과 사용자 확보
초기에는 반복적으로 같은 여행지나 고향을 방문하는 가족을 대상으로 합니다. 가족 단위의 초대는 자연스러운 연결 방식이지만, 초대만으로 성장이나 재방문이 발생한다고 가정하지 않습니다. 첫 기록 생성, 같은 장소 재방문, 실제 청취 완료의 전환을 구분해 측정합니다.
검증 목표
첫 8주 파일럿은 50가족·약 100명의 동의한 참여자를 목표로 설계합니다. 첫 사용 세션의 캡슐 생성률 60%, 4주 내 재사용률 30%, 오류 없는 청취 완료율 95%를 가설적 목표로 설정합니다. 3개월 MAU 200명은 초기 모집과 초대 실험을 위한 계획치이며 실제 이용자 수나 예측이 아닙니다. 여행 빈도가 낮은 특성을 고려해 월간 유지율 외에 ‘해당 장소를 다시 방문한 사용자 중 청취한 비율’을 따로 측정합니다.
수익과 확장
기본 녹음·현장 청취는 무료로 제공하고, 가족 아카이브의 저장 공간 확대와 기기 간 이전을 구독 후보로 검증합니다. 가격과 결제 의향은 인터뷰 및 사용 실험 후 결정합니다. 장기적으로 지자체의 공식 여행 해설 캡슐, 관광지 이야기로 확대하되 주행 중 광고와 무분별한 알림은 제공하지 않습니다. 제휴나 매출이 확보된 상태는 아닙니다.
장기 보관은 운영비, 데이터 내보내기, 서비스 종료 시 이전 정책이 함께 검증돼야 합니다. 유료 구독을 해지해도 이용자가 원본을 회수할 수 있도록 하는 정책을 우선 설계합니다.

## 참고자료

차량 UI 시안, 웹 프로토타입, 네이티브 소스와 서명한 0.3.0 release APK를 준비했습니다. 현재 구현의 근거는 네이티브 자료입니다. 이전 웹 시안은 일부 청취 규칙이 달라 설계 경과를 보여주는 참고자료로 구분합니다. 검증 자료에 위치·주행 제한 수신, 내비 앱 전면 유지, 시스템 미디어 키 재생·재개, 내비 유형 오디오 포커스 시험, 주행 중 기록 명령·자동 저장·중단 임시보관을 포함합니다.
영상·GitHub 공개 링크는 아직 발급하지 않았습니다. 팀명 확정 후 APK 이름을 ‘팀명_타임캡슐_release.apk’로 변경합니다. 참가자 정보와 동의·서명은 본인이 작성합니다. 로컬 서명과 에뮬레이터 성공은 실차 검증이나 Pleos App Market 승인을 뜻하지 않습니다.
설계 근거는 공식 접수양식, Pleos UI·주행 규제·Music/Audio·오디오 포커스 개발 가이드와 Google Design for Driving입니다. 구현·미검증 범위와 재현 절차는 README 및 버전별 검증 결과에 기재합니다.

## 숏폼 링크
